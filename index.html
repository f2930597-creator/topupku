Cara top-up di TopUpKu

  1. Pilih game dan masukkan ID pemainmu.
  2. Tekan Cek ID untuk memastikan nickname akunmu benar.
  3. Pilih paket, lalu bayar dengan QRIS.
  4. Pesananmu bisa dicek di halaman Aktivitas dengan nomor pesanan.
